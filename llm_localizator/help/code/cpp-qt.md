## For people

- Qt: wrap every visible string in `tr("…")` (or `QCoreApplication::translate`), use `%1`, `%2` for arguments and `%n` for plurals; extract with `lupdate` into `.ts` files.
  wxWidgets and GTK use `_("…")` with gettext `.po` files.
- `new QLabel("Save")`, `setText("…")`, `QMessageBox::warning(this, "…", "…")` without `tr` are hardcoded text. Designer `.ui` files carry text too; the `translatable` flag is on by default.
- Add a disambiguation comment as the second argument of `tr` when the English word is ambiguous.
- Do not translate text that is only printed to `qDebug`, or protocol strings. A command-line tool's `printf` text is user text.

## For agents

1. Scan: `llm-localizator agent-hardcoded`. C and C++ are read by the literal detector plus the sink table above; Qt Designer `.ui` files are read for label text.
   The routed calls (`tr`, `_`, `gettext`) are skipped.
2. Fix by wrapping the string in `tr(…)`; the catalogue (`.ts`) is regenerated by `lupdate`. The catalogue format for `.ts` is not supported yet; gettext `.po` and XLIFF are.
3. Keep `%1`, `%2` and `%n` unchanged in translations.
