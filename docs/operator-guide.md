# Operator guide

The guide for the person who owns localization is packaged with llm-localizator:
`llm-localizator help human`, source [`llm_localizator/help/human.md`](../llm_localizator/help/human.md).

It covers:
- choosing how to localize (local, cloud, agent, human, hybrid);
- the decisions only a person makes;
- the workflow as commands;
- how to read `check-keys`, `validate` and QA crawl reports;
- what to run in CI;
- known traps.

AI agents follow `llm-localizator help agent` ([source](../llm_localizator/help/agent.md)).
